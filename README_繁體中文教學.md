## 🎯 什麼是 HLS (M3U8) 與社群全能下載器？

平常我們在網頁上看影片時，許多網站採用切片串流技術（HLS / M3U8），把長影片切成成千上萬個 `.ts` 小碎片，瀏覽器本身的右鍵功能無法儲存這種影片。
而在社群平台（如臉書與 IG）上，影片常常伴隨著自適應解析度跳動、廣告穿插或多頁輪播等複雜結構。

我們的 **HLS & 社群全能下載器** 具備以下核心超能力：
1. **M3U8 萬能解密下載**：自動嗅探播放清單，多通道並行高速抓取，並以大端序修復核心自動完成 AES-128 加密解密，合成完整 MP4！
2. **臉書長短片 0 破格錄製**：獨家「畫布雙緩衝防震牆」與 5 Mbps 高碼率，徹底消滅 52 秒以上長片在錄製時發生的花屏破格與色彩撕裂！
3. **IG 限動置頂居中一鍵下載**：螢幕頂部水平居中控制面板，直覺大氣；支援官方 React 樹狀結構 0 秒極速無損提取！
4. **IG 輪播分頁精準定址**：切換到哪一頁就下載哪一頁（支援 `?img_index=N`），具備媒體型態防護牆，絕不再讓縮圖 JFIF 冒充影片！

## 🛠️ 第一步：如何在 Google Chrome 瀏覽器中安裝？（只需操作一次）

請跟著老師的步驟一步一步做：

1. **開啟 Chrome 瀏覽器**。
2. 在網址列輸入：
   ```text
   chrome://extensions/
   ```
   然後按下鍵盤的 **Enter**。
3. 查看畫面**右上角**，找到 **「開發人員模式」** 開關，請點擊將它**開啟**（開關變成藍色）。
4. 開啟後，左上角會出現按鈕，請點擊最左邊的 **「載入未封裝項目」**。
5. 在跳出的資料夾選擇視窗中，瀏覽並選取本專案目錄中的 **`v3`** 資料夾：
   選取好後按下 **「選擇資料夾」**。
6. 太棒了！你會看到清單中出現了 **「HLS & 社群全能影片下載器」**（版本號為 2.4.0）！
7. **釘選小圖示**：點擊 Chrome 右上角的「拼圖」圖示，找到我們的下載器，點一下右邊的「圖釘」圖示，讓它固定在瀏覽器右上角方便隨時使用。

## 🎬 第二步：三大模式使用教學

### 方式一：下載 M3U8 / HLS 串流影片
- **邊看邊抓（最常用）**：在影音網頁播放影片時，右上角下載器圖示會跳出紅色數字，點開面板即可點擊「立即下載」。
- **手動貼上網址**：複製 M3U8 網址後，打開下載器面板，在上方輸入列貼上並點擊「+ 新增任務」，立即啟動多執行緒高速解密下載！

### 方式二：備份 Facebook (臉書) 個人影片與 Reels
- 進入自己的 Facebook 影片或 Reels 播放頁面。
- 播放器右上角會自動浮現 `📥 下載 Facebook Reel (MP4 音畫合一)` 按鈕。
- 點擊後系統會以 1:1 原速無損串流接管，配合 5 Mbps 高碼率畫布防震牆，錄製出無瑕疵的完整 MP4 影片！

### 方式三：備份 Instagram (IG) 個人限動與輪播貼文
- **限時動態 (Stories)**：
  進入限動播放畫面時，螢幕頂部正中央會浮現醒目的 `📥 一鍵下載當前 Instagram 限動 (影片/照片)` 按鈕，無論是照片還是影片，點擊立即瞬間存檔！
- **多頁輪播貼文 (Carousel)**：
  打開帶有多頁輪播的貼文，切換到特定頁面（例如第 3 頁是影片），按鈕會聰明地標記 `📥 下載 Instagram 輪播影片 (第 3 頁)`，一鍵精準下載真實的 MP4 影片，不再誤抓縮圖！

## 📚 歷史開發演進回顧 (v43 ~ v66)

老師和同學歷經了數十個版本的迭代優化，重要里程碑如下：
- **v44**：修復嚴重的 AES-128 大端序解密問題，奠定串流下載基礎。
- **v45 ~ v60**：逐步納入社群平台解析、側邊欄定址與廣告隔離。
- **v61**：DOM 本體直接接管，杜絕全域假推薦與廣告干擾。
- **v62**：修復 1:1 原速錄製時長壓縮問題。
- **v63**：突破長片逾時保護，成功錄下 52 秒長片。
- **v64**：獨創畫布雙緩衝防震牆與 5 Mbps 高碼率，徹底消滅動態串流破格花屏！
- **v65**：IG 限時動態頂部居中控制面板與 React 官方直連 0 秒極速無損導出。
- **v66**：IG 輪播貼文分頁精準索引與媒體型態防護牆，徹底解決影片誤抓縮圖問題。
