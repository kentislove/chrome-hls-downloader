## 🎯 什麼是 HLS (M3U8)？為什麼需要這個工具？

平時我們在網頁上看影片時，很多網站並不是把一整部幾百兆的影片直接傳給你，而是把影片切成好幾千個「小碎片（.ts 檔案）」，並用一份「播放清單（.m3u8 檔案）」記錄順序。
一般的瀏覽器下載按鈕沒辦法下載這種切片影片，而我們的這個「HLS 串流影片下載器」可以做到：
1. **自動偵測**：當你在網頁上看影片時，它會在背景幫你抓到 `.m3u8` 播放清單。
2. **多執行緒下載**：同時開 3 到 5 個通道，把好幾千個小碎片飛快下載回來。
3. **AES-128 自動解密**：如果影片碎片有加密保護，它會自動取得金鑰並解密。
4. **自動合成完整影片**：下載完後直接組裝成標準的 `.mp4` 或 `.ts` 影片檔案，讓你可以在電腦隨時離線播放！

## 🛠️ 第一步：如何在 Google Chrome 瀏覽器中安裝？（只需操作一次）

請跟著老師的步驟一步一步做：

1. **開啟 Chrome 瀏覽器**。
2. 在網址列直接輸入：
   ```text
   chrome://extensions/
   ```
   然後按下鍵盤的 **Enter**。
3. 查看畫面**右上角**，找到一個開關叫做 **「開發者模式」**，請點擊將它**開啟**（開關變成藍色）。
4. 開啟後，左上角會出現三個按鈕，請點擊最左邊的 **「載入未封裝項目」**。
5. 在跳出的資料夾選擇視窗中，瀏覽並選取本專案的 `v3` 資料夾：
   ```text
   F:\雜記\v44_HLS_Downloader_Fix_Decrypt\v3
   ```
   選取好後按下 **「選擇資料夾」**。
6. 太棒了！你會看到清單中出現了 **「HLS 串流影片下載器 (繁體中文版)」**！
7. **釘選小圖示**：點擊 Chrome 右上角的「拼圖」圖示，找到我們的下載器，點一下右邊的「圖釘」圖示，讓它固定在瀏覽器右上角方便隨時使用。

## 🎬 第二步：如何下載 M3U8 影片？

我們提供三種超方便的使用方式：

### 方式一：直接貼上 M3U8 網址下載（針對已有網址）
1. 點擊瀏覽器右上角的擴充套件圖示，會彈出下載器主介面。
2. 在最上方的輸入列：
   `在此貼上 M3U8 串流網址或影片連結 (例如: https://.../video.m3u8)`
3. 貼上你的目標網址（例如你提到的範例網址），按下旁邊的 **「+ 新增任務」**（或按鍵盤 Enter）。
4. 清單中就會出現該任務，點擊右側的 **「立即下載」** 按鈕。
5. 瀏覽器會跳出存檔視窗，選擇你要儲存在電腦中的位置與檔名，點擊儲存，下載器就會開始全速並行下載與解密組裝囉！

### 方式二：邊看影片邊自動下載（最常用）
1. 打開你平時觀看影片的網頁並點擊播放。
2. 觀看右上角的擴充套件圖示，當網頁加載串流時，圖示右上角會出現數字角標（代表抓到幾個串流）。
3. 點擊擴充套件圖示，面板中會列出抓到的影片。
4. 點擊 **「立即下載」** 即可一鍵儲存！

### 方式三：拖曳或貼上
- 你可以直接把網頁上的影片超連結拖進下載器視窗。
- 也可以把本機的 `.m3u8` 檔案直接拖進下載器視窗。
- 在下載器視窗內按 **Ctrl + V**，會自動提取剪貼簿中的影片網址！

4. **預設封裝升級**：
